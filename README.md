# Drew Disc

A low-poly browser disc golf game, made for Drew's birthday. Mobile first, works on a computer.
First hole: North SeaTac Park, hole 1 (par 3, 360 ft).

```bash
npm install
npm run dev     # game at http://localhost:5173, flight lab at /tools/flight-lab.html
npm test
npm run build   # -> dist/
```

Design and architecture: [docs/DESIGN.md](docs/DESIGN.md). Deploys: [deploy/SERVER.md](deploy/SERVER.md).
